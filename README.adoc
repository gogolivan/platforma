== Development Containers
Platforma uses Development Containers (https://containers.dev/) to provide consistent development environments for each module.

== Modules
* `platforma/actions`: GitHub Actions
* `platforma/catalog`: Software Catalog
* `platforma/proto`: Protocol Buffers definitions
* `platforma/features`: Dev Container Features
* `platforma/skills`: Agent Skills
* `platforma/operators`: Kubernetes Operators

== Sandbox
The `platforma/sandbox` module serves as a strictly isolated environment for building and running modules.

[NOTE]
====
For production, it is recommended to run each module with https://katacontainers.io/[Kata Containers] _microVM_ container runtime by setting the `--runtime=kata-runtime` _Docker_ flag.
====

== Configuration
=== Firewall
`platforma/features` **firewall** sets up firewall rules to restrict network access within containers.

=== Scanner
`platforma/features` **scanner** integrates security checks.

[NOTE]
====
Dev Container Features scripts can be used outside of Development Containers configuration and run in any compatible environment.
====
